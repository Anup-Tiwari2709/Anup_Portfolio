# Anup Tiwari - Portfolio Website

A professional, modern portfolio website showcasing DevOps engineering expertise, cloud solutions, and technical achievements.

## 🌟 Features

- **Responsive Design** - Fully responsive on desktop, tablet, and mobile devices
- **Modern UI** - Clean, professional design with smooth animations
- **Dark Mode Ready** - CSS variables for easy theme customization
- **SEO Optimized** - Semantic HTML and meta tags
- **Accessibility** - WCAG compliant with keyboard navigation
- **Performance** - Optimized for fast loading and smooth interactions

## 🚀 Quick Start

1. **Open in Browser**
   - Simply double-click `index.html` or open it in your web browser
   - No installation or server setup required

2. **Customize**
   - Edit `index.html` to update content
   - Modify colors in `css/styles.css` (look for `:root` CSS variables)
   - Enhance functionality in `js/script.js`

## 🎨 Customization

### Colors
Edit the CSS variables in `css/styles.css`:

```css
:root {
    --primary-color: #007acc;      /* Main blue */
    --secondary-color: #ff6b6b;    /* Red accent */
    --accent-color: #20c997;       /* Green accent */
    --dark-bg: #0d1117;           /* Dark background */
    --light-bg: #f6f8fa;          /* Light background */
    --text-dark: #24292e;         /* Dark text */
    --text-light: #6e7681;        /* Light text */
}
```
